# 手机体验与公共信息设计

保留暖白、灰粉与 AMC 标志，继续使用编辑式图文阅读布局。桌面保留现有三栏卡片，手机采用原生可展开专栏菜单、单列文章卡片和更大的正文字号，避免导航依赖横向滑动。

另一种可选方案是只放大字体并调整间距，改动更少，但无法完整解决专栏入口难发现的问题。本次采用原生菜单方案，不引入新的运行时依赖。

正文在手机上以 18px 排版，主要点击区域至少 44px。兼顾 320px 小屏、常见手机宽度、平板与桌面；支持安全区域、键盘焦点、减少动画偏好和无 JavaScript 的专栏导航。

新增隐私声明与开源说明，页脚集中维护并静态写入所有页面，包含 404 页。隐私声明区分页面功能与服务器访问日志，不承诺未经验证的“完全不收集信息”。

公共代码采用 MIT 许可，正文、素材与品牌标志单独说明。GitHub 公开仓库仅包含站点静态文件、维护脚本、测试和文档，不包含生产凭据、日志和备份。

校验覆盖文章正文不变、240 个图文入口不变、全部内部链接和图片有效、页脚一致、手机菜单可达、键盘与无脚本回退，以及公开仓库的敏感信息排查。
